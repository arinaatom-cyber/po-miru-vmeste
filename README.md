# По миру вместе

Статический сайт с реальными маршрутами наших поездок: города, что смотреть, где жить и где есть, карты с точками пути.

Разделы: маршруты (авто, яхты, самолёт), веломаршруты и «Где мы жили» — сводка по жилью со всех поездок.

## Локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
cd soul-trips
python -m http.server 8777
```

Затем откройте `http://localhost:8777/index.html`.

## GitHub Pages

1. Создайте репозиторий на GitHub (например `po-miru-vmeste`).
2. Загрузите содержимое папки `soul-trips` в корень репозитория.
3. **Settings → Pages → Source**: Deploy from branch `main`, folder `/ (root)`.
4. Сайт будет доступен по адресу: `https://ВАШ-ЛОГИН.github.io/po-miru-vmeste/`

### Быстрая загрузка через git

```bash
cd soul-trips
git init
git add .
git commit -m "По миру вместе: маршруты"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/po-miru-vmeste.git
git push -u origin main
```

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка: шапка, hero, маршруты, веломаршруты, жильё, контакты |
| `routes.js` | `window.ROUTES` — маршруты: путь, остановки, активности, советы |
| `meta.js` | `window.ROUTE_META` — фото, транспорт, категория, координаты для карт |
| `app.js` | Фильтры, страницы маршрутов, карты Leaflet, навигация по hash |
| `styles.css` | Оформление (один шрифт Manrope, светлая тема) |

Внешние зависимости: Leaflet 1.9.4 и плитки Carto через CDN, шрифт Manrope из Google Fonts. Сборка не нужна.

## Как добавить маршрут

1. Запись в `routes.js`: `id`, `title`, `region`, `about`, `path` (порядок городов), `stops` (для каждого — `name` и `activities`), `tips`, при наличии — `source` (ссылка на Telegraph).
2. Блок в `meta.js` с тем же `id`: `transport` (`car` / `yacht` / `plane` / `bike`), `transportLabel`, `category`, `image`, `mapCenter`, `mapZoom` и `stopCoords` для каждой точки из `path` и `stops`.

Как это влияет на сайт:

- точки из `path` рисуются на карте нумерованными маркерами и соединяются линией — порядок важен;
- активности автоматически раскладываются по блокам («Что посмотреть», «Жильё и отели», «Заведения», «Транспорт и чартеры», «Логистика») по ключевым словам в тексте (функция `categorize` в `app.js`);
- всё, что попало в жильё, дополнительно собирается в блок «Где остановиться» на странице маршрута и в раздел «Где мы жили» на главной, а заведения — в блок «Куда сходить», поэтому названия отелей, кафе и адреса пишите прямо в тексте активности;
- ссылки (полные URL и домены вида `example.ru`) становятся кликабельными автоматически;
- `transport: ["bike"]` выносит маршрут в отдельную секцию «Веломаршруты», `planned: true` в `meta.js` помечает маршрут как «Скоро».

Данные берутся только из наших поездок и исходников Telegraph. Если информации нет — оставляйте пусто, блок не отрисуется.
